## Instalação e Uso 
1. Clone o repositório: git clone https://arielesilvaa.github.io/ano-novo/
2. Acesse a pasta do projeto: cd nome-do-repositorio 
3. Instale as dependências (se houver): npm install 
4. Inicie o projeto: npm start
